# Sales-Revenue-KPI-Analysis
**This dashboard tracks total units, revenue, quarterly performance, and regional breakdowns — all in one view**

**Key Takeaways:**

⚡Data Concepts: KPIs (Revenue Achievement, Target Variance), Trend Analysis, Regional & Product Segmentation, Quarterly Comparisons.

🌐Platforms: Power BI Service for sharing and collaboration, LinkedIn for professional showcase.

💡Designed to support data‑driven decisions by combining clean visuals, interactive filters, and storytelling titles.

**Technical Breakdown:**

🔧Tools Used: Power BI Desktop, DAX measures, Conditional Formatting, Excel.

🧹Data Cleaning: Power Query (ETL) for removing nulls and formatting currency.

🎨UX/UI: Custom color palette (#2DA591) (#D83B01) (#D3D3D3) for brand consistency and high-contrast accessibility.
